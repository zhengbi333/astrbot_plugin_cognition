# alpha-1.5.4

## 修：保存显示「没有改动」、填的 QQ 号"消失"

**先说结论：数据没丢。** 配置文件里一直是 `"admins": "10001"`。

真正的问题是**读**：

```python
plugin.config.get("auth.admins")   # ← 返回 None（点号路径不可靠）
```

面板用这个取值，于是：

1. 打开设置页 → 读到 `None` → 输入框**显示空**（你看到"QQ 号不见了"）
2. 你重新填一遍 `10001` → 和文件里**已经一样** → `changed` 为空 → 提示**"没有改动"**
3. 点保存 → 重绘 → 又读到 `None` → **又变空**（你以为被清掉了）

**修法**：面板取值**直接读配置文件**，不再经过 config 对象：

- 新增 `read_config_file()` + `_nested()`，文件是唯一真相；
- 文件里没有的键才回退到 `config.get`，再没有才用 schema 的默认值；
- 实测：即使把 `config.get` 打桩成永远返回 `None`，`auth.admins` 仍能读到 `10001`。

## 新增测试（`audit_82` 从 18 条增到 22 条）

专门打这个坑：

- **B2a** `config` 拿不到时仍能从文件读到；

- **B2c** 保存后能读回新值（`999888777`）；
- **B2d** `changed` 非空。

## 已知边界

- 面板写配置会**同时**更新文件与内存中的 config 对象（`plugin.config.update()`），
  但 AstrBot 是否立刻用上新值取决于它自己的缓存策略 —— 少数项（如管理员名单）重载后最稳。
