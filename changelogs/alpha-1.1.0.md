# alpha-1.1.0

## 新增技能库（对应 DSH 的 skill）

之前每件活都靠模型临场推理"该怎么做"：既不稳定，也浪费 token。
现在可以把**一类活的标准流程**写成文件，模型在需要时取一份照着做。

| 工具 | 作用 |
|---|---|
| `toolbox_skill_list` | 列出技能（可按关键词过滤），带一句话说明 |
| `toolbox_skill` | 取某份技能的完整流程 |

### 存哪、怎么写

`~/.astrbot/data/plugin_data/astrbot_plugin_cognition/skills/*.md`

```markdown
# 做周报

> 把本周的零散记录整理成一份能发出去的周报。

1. 先用 toolbox_fs_search 找齐素材；
2. 用 toolbox_doc_write 生成 docx；
3. 用 toolbox_send_file 发出去。
```

- 一级标题当名字，`> ` 引言当说明（没有引言就取正文首句），正文随便写步骤；
- 也支持 `name:` / `description:` 字段声明；
- 超 6000 字截断，隐藏文件跳过。

### 安全设计

- **模型只能读，不能写**：没有"保存技能"的工具 —— 否则它可能给自己写一份"绕过规则"的流程；
- 技能只是文本流程，**不能改变权限**（权限在 `auth` 配置里，技能里写"可以全盘访问"也没用）。

### 内置三个示例（首次启动写入，不覆盖已有）

- **做周报**：搜素材 → 分三段 → 出 docx → 可选 PDF → 发送
- **整理会议记录**：抽结论/待办/悬案 → 写 docx → 发送
- **批量改文件名**：先列清单 → 脚本只打印将要改的 → 记录旧名到 rename-log.json → 再执行

## 验证

`_st_test/audit_70_skills.py` —— **22/22**：
内置示例写入与幂等、标题/字段两种名字来源、`>` 引言作说明、文件名查找、大小写不敏感、
超长截断、隐藏文件跳过、清单格式、接线与"没有写技能的工具"。

## 已知边界

- 技能没有参数（不做模板变量替换）；
- 不校验技能内容的安全性（它是给人写的，风险由编写者承担）；
- 技能目录不随插件升级更新（内置示例只补缺失，不覆盖你改过的）。
