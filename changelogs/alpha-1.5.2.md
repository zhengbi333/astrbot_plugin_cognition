# alpha-1.5.2

面板从"只能看"变成"能改"。

## 新增「06 设置」页签

- **17 个分组、52 个配置项**，全部在面板里直接改，不用再点齿轮；
- **每一项都带说明**：中文标题 + 一段「这是干什么的」+ 灰色小字显示真实配置键名
  （`page_config.py` 检查过：**0 项缺说明**）；
- 控件按类型自动选：布尔 → 拨杆开关、数字 → 数字输入、枚举 → 下拉、长文本/JSON → 多行框；
- 底部「保存」一次提交全部改动，**写前自动备份**（同目录 `xxx.bak-时间戳.json`），**原子写**（先 .tmp 再替换）。

## 安全约束

- 只接受 `_conf_schema.json` 里声明过的键，前端塞别的字段会直接报错；
- 值按 schema 的类型回转（`"true"` → `true`、`"30"` → `30`、JSON 字符串 → 对象）；
- 写后尝试 `plugin.config.update()` 让插件立刻读到新值；部分配置（如管理员名单）仍需重载完成切换，
  面板里已提示。

## 后端

## 已知边界

- 设置页**只覆盖认知插件**（人格/记忆各有自己的面板）；
- 极少数需要重启才能生效的项（如 `exec.owner_ids` 影响权限缓存）面板里会保留重载提示；
- 不提供「恢复默认」按钮（怕误点把配置清空）—— 需要时从备份文件拿。
