# alpha-1.5.0

## 新增 WebUI 面板（终末地风格）

之前只能点配置小齿轮改几十项 —— 其中 `workspace.mapped`、`delegate.agents` 这类还得手写 JSON，
很容易写错。现在有了自己的面板。

### 六个页签

| 页签 | 内容 |
|---|---|
| **总览** | 版本、工具数、工作区（模式 + 访问级别 + 路径）、子代理额度、目标/技能/记录计数、权限分级、工具清单（可展开） |
| **专家** | 每个子代理的说明与系统提示、用哪个模型、输出上限；今日已用/上限/剩余 |
| **目标** | 长期目标列表 + 立新目标 + 完成/放弃 |
| **技能** | 技能清单与说明，点开看完整流程 |
| **记录** | 最近 120 条动作（工具、成功与否、谁用的、时间），可清空 |
| **关于** | 设计取舍与风险提示 |

### 视觉：照着《终末地》UI 原则做

参考 [《终末地》UI 设计分析](https://blog.harryh.cn/Design/UI-Philosophy-Of-Endfield/) 的几个核心特性：

| 特性 | 这里的做法 |
|---|---|
| **强调色块** | 黑底 + 亮黄（#f2e14c）；选中的页签整块黄底黑字 |
| **克制圆角** | 几乎全直角（`border-radius: 0`），只有扁按钮用大圆角 —— 和原作一致 |
| **几何底纹** | 48px 等距网格 + 极淡扫描线，叠加一层顶部黄光 |
| **等宽字体** | 全局 `ui-monospace`，技术标注全大写 + 字距 |
| **编号与坐标** | 页签 01–06；右上角实时显示 `X/Y` 坐标读数（原作重力跟随的降级版：跟鼠标，不做 3D 旋转） |
| **快速闪动** | 提示条用 25ms×2 的闪入；**大块元素不用**（避免光敏风险，也避免 headless 截图卡在 opacity 0） |
| **激进缓动** | `cubic-bezier(0.87, 0, 0.13, 1)`（类 easeInOutExpo），用于 hover 与状态过渡 |

### 后端接口

`page_api.py`，前缀 `/astrbot_plugin_cognition`：

```
GET  /overview          状态、权限、额度、工具清单
GET  /experts           专家列表 + 今日额度
GET  /goals             目标列表（?all 含已结束）
POST /goals/add         立目标
POST /goals/close       完成/放弃
GET  /skills            技能清单
GET  /skills/read?name= 技能正文
GET  /audit             最近 120 条动作
POST /audit/clear       清空记录
```

请求/响应对象沿用三个插件统一的**三级回退**（quart 代理 → api.web 代理 → quart 自带），
面板挂载失败只警告、不影响插件本体。

## 验证

- `mock_panel_server.py` 起本地服务，用 headless Edge **截图实测**三个页签（总览/专家/目标），
  确认渲染正常、无空白、无错位；
- 修了一个真问题：`.cell` 的入场动画（`opacity: 0 → 1`）在 headless 的 virtual-time 下会**卡在不可见**，
  导致内容区一片空白 —— 已移除所有会隐藏内容的入场动画，只保留装饰性闪动；
- 工具清单默认折叠前 8 条（32 条全列会占满一屏）；
- 路径改为 `break-all`，不再被中文字符断得七零八落；
- 全量回归 **690/690**、一键验收 **42/42**（含本轮新增的配置类型与面板检查）。

## 已知边界

- 面板**只读配置**：`workspace`、`auth`、`delegate.agents` 这些仍要去齿轮改（面板只展示结果）；
  本轮只让「目标」可写（那是运行时数据，不是配置）。
- 没有 3D 重力跟随（原作是终端界面的视差，Web 面板做这个收益低）。
- 面板不显示实时日志流。
