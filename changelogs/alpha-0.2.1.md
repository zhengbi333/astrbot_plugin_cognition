# alpha-0.2.1

## 一句话

从「9 个工具」到「13 个工具」，并补上这个插件名字真正承诺的那件事：**汲取经验**。

## 新增工具

### `toolbox_learn` —— 汲取经验（本版核心）

给一个网址，或给一个搜索词：

1. 有网址就抓正文；只有搜索词就先搜（Tavily），取首条结果再抓；抓不到正文则退化为"用搜索摘要本身"；
2. 用 `notes.py` 生成带 front-matter 的 Markdown 条目（`title` / `fetched_at` / `source_url` / `search_query`）；
3. 写进工作区 `notes/2026-10-26-<slug>-<时分>.md`；
4. 回给模型一段要点摘要（默认 600 字），并注明完整内容在文件里。

文件名规则：`<日期>-<标题slug>-<时分>.<ext>`，同一天同一页多次抓取也不会互相覆盖（靠时分区分）。

### `toolbox_doc_read` / `toolbox_doc_write` —— Office

- 读：`.docx` 段落 + 表格（前 12 行）、`.xlsx` 工作表（每表前 40 行、前 12 列），都有字数上限；
- 写：`.docx` 按行写段落（`- ` 开头为列表项，可选一级标题）、`.xlsx` 按行写表格
  （`|` / 制表符 / 连续两空格分隔都可，自动跳过 Markdown 表格的 `---|---` 分隔行）；
- 依赖 `python-docx` / `openpyxl`（AstrBot 环境自带）；缺失时给出可读错误而不是崩。

### `toolbox_audit` —— 自查

返回最近 N 次调用（时间、工具、成功/失败、备注）+ 按工具统计。**故意不加门禁**：
它是"我到底动过什么"的自我举证通道。

## 已知边界

- `toolbox_learn` 只处理单页；不做多页递归抓取（避免无界抓取）。
- Office **只做摘要读与从零写**，不保留/不精修原格式（改格式请用专业工具）。
- `.pptx` 未支持（AstrBot 环境目前没有 `python-pptx`）。
- 抓取仍只支持 http/https 且不执行 JS（SPA 页面会抓到空正文并如实报错）。
