# alpha-1.0.0

这一版是**架构升级**：从"一个共用工作区 + 单一 owner 判定"变成
"**按会话分配工作区 + 三级权限 + 用 Python 补齐缺失软件**"。

## 一、权限分级（像 AstrBot 管理员认证那样）

| 等级 | 认定方式 | 能力 |
|---|---|---|
| 管理员 | `auth.admins`（留空回退 `exec.owner_ids`） | 代码执行、后台任务、shell、全盘访问 |
| 成员 | `auth.members` | 工作区读写、文档、发文件、导出 PDF、图片 |
| 访客 | 其他所有人（默认） | 聊天、搜索、抓网页、读资料 |

- **fail-closed**：认不出身份 → 访客；名单为空 → 没人能当管理员（不是"所有人都是"）。
- 高风险动作逐个过门：`write / office / download / send / exec / task / shell / archive / image`。
- `auth.members_open` 可以把未登记的人放成成员（默认关）。

## 二、工作区按会话分配

| 模式 | 行为 |
|---|---|
| `shared` | 所有会话共用一个工作区（默认，和以前一样） |
| `per_session` | 每个会话 `workspace/sessions/<前缀-哈希>/`，互不可见 |
| `mapped` | `workspace.mapped` 里显式写「会话 → 目录」，`*` 为默认；**支持绝对路径** |

访问级别：
- `workspace`（默认）：路径监狱，只能在本会话工作区内；
- `full`：可访问工作区外，**只有管理员**能开，非管理员自动降级；
  再用 `full_roots` 限定可访问的根目录，**留空 = 真全盘**（所以默认留空但默认不开 full）。

另外：`mapped` 的 JSON 允许手写 Windows 反斜杠路径（会自动容错），不用记着打双反斜杠。

## 三、用 Python 补齐缺失的软件

这三样以前都要外部程序，现在不需要：

| 新工具 | 替代了什么 | 实现方式 |
|---|---|---|
| `toolbox_doc_export` | **LibreOffice**（docx/xlsx/pptx → PDF） | Pillow 逐页渲染成图片，再存多页 PDF；中文用系统字体（微软雅黑/黑体/宋体/苹方/Noto 自动探测）。**代价**：PDF 里是位图、文字不可复制，结果里会如实说明 |
| `toolbox_image` | 图像软件（缩放/压缩/水印/格式转换） | Pillow |
| `toolbox_archive` | 压缩软件（zip/tar 打包解包） | 标准库 + 硬约束：拒绝 `..` 与绝对路径条目、条目数 ≤500、解压总量 ≤200MB、单条目压缩比 >200 直接判为炸弹 |

## 五、已知边界

- PDF 是位图（文字不可复制/不可搜索）；要可选文字得装 LibreOffice，本版不做。
- 图片处理只做四种基本操作，不做抠图/超分/滤镜。
- 解包不支持 7z/rar（标准库没有）。
- `per_session` 模式下，后台任务的日志仍写在**共用**工作区（任务表是插件级的），这是已知差异。
