# alpha-0.1

首个版本：把"动手的能力"从零做成一个独立插件，与记忆、人格三权分立。

## 定位

「为你篆刻的历史」管**过去**（记得什么）、「为你续写的故事」管**此刻怎么说**（人格与表达）、
「为你而在的认知」管**能不能真的去做**（读、搜、抓、下、跑）。

LLM 本身不能读盘、不能联网。没有工具时它会"假装做过"（回复"我读过了"其实什么都没读）。
本插件让这些动作**真的发生在机器上**，并把结果如实交回模型；失败时给出明确文案，模型才会老实说"没查到"。

## 安全设计（本版的骨架，不是补丁）

1. **路径监狱**：一切路径经 `resolve()` 后必须仍在 `plugin_data/<plugin>/workspace` 内；
   `..`、绝对路径、盘符、符号链接逃逸一律拒绝。
2. **SSRF 拦截**：抓取/下载会校验主机名与**解析后的 IP**，
   `127./10./172.16-31./192.168./169.254./localhost/.local/.internal` 等直接拒绝 ——
   否则群里任何人都能借 Bot 读你自己的 WebUI 或局域网设备。
3. **敏感文件拒读**：`.env` / `*.pem|key|pfx` / `id_rsa` / `*secret*` / `*credential*` 即便在工作区内也不碰。
4. **体积与超时**：读（默认 256KB）、写（1MB）、下载（50MB）、抓取（2MB）都有上限；网络与命令都有超时，
   命令超时**强杀**。
5. **命令默认关闭**：开启后只认白名单里的**程序名**（不含路径分隔符），并且
   `bash/cmd/powershell/python/node/java/reg/schtasks/...` 这类"任意执行入口"**写进白名单也一律拒绝**；
   不使用 `shell=True`，参数按列表传递。
6. **每日剂量**：`limits.daily_calls`（默认 200）防刷爆。

## 已知边界

- 只做 `http/https`，**不执行 JS**（抓不到 SPA 渲染后的内容，如实失败）。
- 下载只校验扩展名白名单与体积，**不查毒**。
- 「为你续写的故事」的**接管改换**模式用自己的一套工具通道，本插件默认只对**主链**生效；
  两边的桥接是下一步（见 TODO）。
- 无独立面板页（v0.1 用配置项管理；面板可读 AstrBot 自动生成的设置页）。
