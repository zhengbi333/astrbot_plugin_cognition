# alpha-1.5.1

## 一、修：面板所有页签「读取失败：Failed to fetch」

原因：`bridge.apiGet/apiPost` **会自己补插件前缀**，而我又传了
`/astrbot_plugin_cognition/overview` —— 前缀重复 → 请求打到不存在的路径 → 404。
人格、记忆两个插件的面板传的都是 `"health"` 这种相对路径。

修法：

- 所有调用改成相对路径（`overview` / `experts` / `goals` …）；
- 启动时**等 bridge 就绪**（最多 3 秒轮询），避免首屏抢跑；
- fetch 兜底改成 `/<plugin>/<path>` 并检查 `res.ok`，失败时给出 HTTP 状态而不是笼统的 Failed to fetch。
